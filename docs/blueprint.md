# **App Name**: GymCentral

## Core Features:

- Dashboard Overview: Display a dashboard with key gym metrics: active members, expiring memberships, monthly revenue, and pending payments.
- Client Management: Manage client database with search, filters, and add new client functionality.
- Membership & Payment Tracking: Configure membership plans and track payments with expiry dates, send reminders to clients.
- Class Organization: Calendar to view scheduled classes and manage details such as instructor, capacity, and time.
- Financial Dashboard: Summarize revenues, membership types, income trends, and client retention metrics.
- Custom Settings: Configure gym details, manage users and permissions, setup payment methods, and manage notifications.

## Style Guidelines:

- Primary color: Saturated blue (#29ABE2) to inspire confidence and energy.
- Background color: Light blue (#E5F5FB) for a clean, open feel.
- Accent color: Teal (#2093B2) to complement the primary color and add depth.
- Clean and modern sans-serif font for readability.
- Simple and professional icons to represent different features.
- Dashboard-style layout for displaying data clearly.
- Smooth transitions and subtle animations for enhanced user experience.
